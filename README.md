# АвтоШер — Каршеринг в Красноярске 🚗

Веб-приложение для поминутной аренды автомобилей.

## 🚀 Технологии
- Python + Flask (backend)
- HTML5 + CSS3 + JavaScript (frontend)
- Leaflet.js (интерактивная карта)
- LocalStorage (хранение данных)
